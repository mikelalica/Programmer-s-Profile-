Featured Project

PassTrack: A Web-Based Academic Status and Deficiency Monitoring Portal for Enrolled Subjects

Capstone Software Project Proposal (2026) | NVSU-CITE

Overview

A centralized, web-based monitoring portal designed for NVSU-CITE students. It provides early, real-time visibility into subject-level standings, coursework requirements, and academic deficiencies during the ongoing semester to replace delayed final grading updates.

Core Frameworks & Implementation

Visual System
Three-tier Red-Amber-Green (RAG) dashboard indicators to track passing, borderline, or critical deficiencies at a glance.
Accessibility
Strict Web Content Accessibility Guidelines (WCAG) compliance, pairing color codes with unique text labels and shapes for low-vision and colorblind users.
Methodology
Developed using the Rapid Application Development (RAD) framework for iterative prototyping and modular integration.
